# Bar María Germiná Tapas

Sitio estático local para la web de Bar María Germiná Tapas.

## Ejecutar

Desde el directorio del proyecto:

```powershell
python -m http.server 8080
```

Abrir `http://localhost:8080/`.

## Desplegar

Subir el contenido del directorio a un servidor web HTTPS o a la plataforma de hosting existente sin cambiar el dominio ni la configuración de producción.
